# KidiGo
KidiGo es un juego educativo donde aprender se convierte en una aventura. 🦊🎮 Juega a retos de matemáticas, letras, colores, lógica y memoria. Consigue KidiStars ⭐, desbloquea logros, mantén tus rachas y personaliza tu personaje con diferentes estilos y accesorios. ¡Aprende, juega y diviértete con KidiGo! 🚀
